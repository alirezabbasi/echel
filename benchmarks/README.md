# Echel benchmark fixtures

This directory contains the machine-readable Echel 2 benchmark catalog. The six scenario manifests are selected semantic fixtures; their lifecycle state indicates whether source repositories and evaluator assets have been materialized and independently validated.

All Echel-authored scenario definitions, synthetic data, future generated fixture source, and evaluator baselines are licensed under the repository’s Apache License 2.0. See [`LICENSE`](../LICENSE) and the license/provenance fields in each manifest.

Do not report benchmark execution results from a manifest whose lifecycle state is only `selected`. See the [benchmark suite contract](../docs/product/benchmark-suite.md) for materialization, fair-run, data, failure, and versioning rules.
