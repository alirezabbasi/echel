# Progressive methodology

The lifecycle is a sequence of uncertainty-reduction capabilities, not a waterfall and not a prescribed directory tree.

Every stage repeats the same operation:

```text
current knowledge + targeted clarification + evidence + owner decisions
→ revised knowledge → maturity assessment → next safe action
```

Knowledge records can be `proposed`, `accepted`, `validated`, `rejected`, or `stale`. Confidence is independent of status. Later findings may make an earlier record stale and require downstream work to be replanned.

The four profiles—prototype, product, production, and regulated—apply
[inspectable, increasingly strict minimum policies](reference/lifecycle-profiles.md)
to the same lifecycle. Regulated is a generic rigor floor, not a claim that
jurisdiction-specific policy packs or certification already exist.

Stage transition checks intentionally remain minimal. They block only when the current stage lacks its small set of accepted knowledge kinds. More detailed checks belong in methodology skills and risk-sensitive policies, not a universal global gate.
